# 🎬 Netflix SQL Data Analysis Project

## 📌 Overview
This project explores and analyzes Netflix's content catalog using SQL. The dataset contains information about movies and TV shows available on Netflix, including details such as title, director, country, release year, rating, duration, and genre.

The goal of this project is to demonstrate SQL skills through real-world business questions involving data exploration, filtering, aggregation, subqueries, and window functions.

## 📂 Dataset

The dataset contains Netflix titles with the following attributes:

- Show ID
- Type (Movie / TV Show)
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre (Listed In)
- Description

## 🎯 Project Objectives

- Explore Netflix content distribution
- Analyze content trends over time
- Identify top-performing countries and directors
- Examine ratings and genres
- Practice advanced SQL concepts using real-world data

---

## 📊 SQL Questions Solved

### Basic Exploration
1. Total number of Movies and TV Shows on Netflix
2. Top 5 countries producing the most content
3. List all content released in 2020
4. Movies directed by Kirsten Johnson

### Content Trends & Filtering
5. Most common content rating
6. TV Shows with 5 or more seasons
7. Indian movies in the Comedy genre
8. Number of releases per year

### Advanced Analysis
9. Top 5 directors with the highest number of movies
10. Year with the highest content additions
11. Five oldest Indian movies on Netflix
12. Documentary movies released after 2015

### Window Functions & Subqueries
13. Longest movie on Netflix
14. Most recently released movie for each country
15. Years with more than 50 Indian movie releases
